# Preview lifecycle

Generated by `python3 scripts/render_lifecycle.py`; checked by the unit suite.

Both systemd and tmux workers execute this table. Systemd publishes state through
StatusText; tmux publishes it to the private atomic registry. A missing tmux worker
observes the error transition without replaying effects; down then performs cleanup.
